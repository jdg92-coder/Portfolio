# Project instructions

## Visual style

- Give every page and shared site component a cohesive old-fashioned cartoon look.
- Use playful, expressive shapes, hand-drawn-inspired details, and a warm, nostalgic palette where appropriate.
- Choose typography that supports the vintage cartoon feeling while keeping all text easy to read.
- Keep the style consistent across pages, including headings, buttons, navigation, forms, and responsive layouts.

## Technology

- Build the website using only HTML, CSS, and JavaScript.
- Do not add frameworks, libraries, build tools, or other programming languages unless the project owner changes this instruction.
- Prefer simple browser-native features and keep the project easy to run as a static website.
